1. Replace placeholder secrets before going to production:

   The following secrets were created with placeholder values.
   Replace them with real cryptographic material immediately:

     {{ include "wslvault.fullname" . }}-root-key   (key: root-key)
     {{ include "wslvault.fullname" . }}-jwt-secret  (key: jwt-secret)

   Generate a root key:
     openssl rand -base64 32

   Generate a JWT secret:
     openssl rand -base64 64

   Update the secrets:
     kubectl create secret generic {{ include "wslvault.fullname" . }}-root-key \
       --namespace {{ .Release.Namespace }} \
       --from-literal=root-key="$(openssl rand -base64 32)" \
       --dry-run=client -o yaml | kubectl apply -f -

2. Check that all pods are running:

     kubectl get pods --namespace {{ .Release.Namespace }} \
       -l app.kubernetes.io/instance={{ .Release.Name }}

3. View logs for a specific service (e.g. secret-engine):

     kubectl logs --namespace {{ .Release.Namespace }} \
       -l app.kubernetes.io/name=secret-engine \
       --tail=100 -f
